# Literature-derived system records

This directory expands the library beyond complete INCAR files. It accepts papers that publish only key computational settings, provided those settings are explicitly verified in the main text or SI.

## Admission levels

| Level | Required evidence | Allowed downstream use |
|---|---|---|
| `full_incar` | Actual INCAR/input archive from SI or a linked repository | Reuse as a versioned reference after compatibility checks; do not call it converged for a new system. |
| `verified_key_parameters` | Main text or SI explicitly states a parameter and its calculation scope | Overlay only the explicitly stated fields on a generic template. Missing fields remain unresolved/reconstructed. |
| `candidate_pending_fulltext` | DOI and chemical system verified, but computational details/SI not yet inspected | Discovery only. No values may be used to generate an INCAR. |
| `rejected` | Ambiguous method, inaccessible evidence, contradiction, or non-VASP calculation | Never route to generation. Retain reason to avoid repeated ingestion. |

## Record rules

- The record unit is a **paper-system-task stage**, not merely a DOI. One DOI may contain separate bulk relaxation, slab adsorption, DOS, band, NEB, and AIMD records.
- Every parameter needs `value`, `units` where relevant, `scope`, `evidence_location`, and `evidence_kind`.
- Preserve what the paper says. Do not convert a statement such as "energy cutoff 500 eV" into `ENCUT=500` unless the code and context make that mapping unambiguous.
- Record KPOINTS, POTCAR, POSCAR model, and code/version outside INCAR because they are equally important to reproducibility.
- Fields not explicitly disclosed go in `missing_parameters`; do not fill them in the evidence record from VASP defaults.
- A completed local INCAR generated by combining evidence and templates must mark every tag as `explicit_source`, `official_default`, `template_choice`, or `system_assumption`.

`records.json` is the machine-readable catalog. `schema.json` defines the record contract. `candidates.json` is a quarantine queue and must never be used for input generation.
