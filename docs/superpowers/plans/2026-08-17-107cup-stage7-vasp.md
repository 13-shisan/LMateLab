# 107 Cup Stage 7 VASP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 107 上交付由网页一次启动、自动推进且科学验收失败关闭的固定 MoS2 `relax -> SCF -> BAND/DOS` 真实 VASP 闭环。

**Architecture:** 保留 `competition_slurm.py` 的固定 argv/归属边界和 `competition_reconcile.py` 的数据库账本；`competition_attempt_inputs.py` 负责不可变 attempt 输入和恢复账本，`competition_vasp.py` 负责纯科学策略，`competition_coordinator.py` 负责自动推进。单 worker FastAPI 服务通过 lifespan 协调器恢复和推进 owned attempts；每一步均先取得可信 Slurm 终态，再由 Pymatgen 和文件哈希执行科学验收，最后才原子领取下一步。

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2, SQLite, Pymatgen 2025.10.7, `unittest`, React 19, Node test runner, Slurm 25.11, VASP 6.4.2 GPU, VASPKIT 1.5.1, Bash, SHA-256 evidence manifests.

def copy_verified_input(
    *,
    source: Path,
    destination: Path,
    expected_sha256: str,
    source_file_id: str,
) -> dict[str, object]:
    content = read_regular_file(source, expected_sha256=expected_sha256)
    write_private_exclusive(destination, content)
    actual = hashlib.sha256(destination.read_bytes()).hexdigest()
    if actual != expected_sha256:

    return {
        "source_file_id": source_file_id,
        "source_sha256": expected_sha256,
        "sha256": actual,
        "size_bytes": len(content),
    }
