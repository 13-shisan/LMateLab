# 107 杯最终演示脚本

更新时间：`2026-08-21`

## 1. 演示前门禁

演示者只使用已经通过 Stage 10 Slurm 验收的固定 `main` 发布。先记录 `final-acceptance.md` 中的 commit、服务 Job、节点、端口、manifest 和 Stage 10 验收 Job。任何健康检查、身份、哈希或角色门禁失败都停止演示，不用旧截图或 demo 数据顶替。

准备两个全新浏览器上下文：一个 Operator，一个 Viewer。不要复用已有 token、缓存或登录状态。Operator 通过 Windows SSH 隧道访问 `http://127.0.0.1:21763`；Viewer 从白名单网络访问 `http://222.195.94.37:18733`。密码由成员现场输入，不记录在视频、截图、终端历史或仓库中。

建议完整演示控制在 10 至 12 分钟，按以下顺序执行。

## 2. Viewer 开场：只读总览

1. 在 Viewer 新会话登录，打开 `/dashboard`。
2. 指出页面显示 live 数据模式和真实服务身份，不出现 demo 标识。
3. 展示工作流统计、成功/失败状态和服务可用性。
4. 打开“新建计算”，确认输入和提交控件禁用；不要尝试绕过界面。
5. 展示 Viewer 的取消、重试等写操作不可用。

验收点：Viewer 能浏览，但不能创建、提交、取消、重试或修改数据；浏览器控制台无错误。

## 3. Operator：固定四步工作流

1. 在独立 Operator 新会话登录，打开 `/dashboard/workflows`。
2. 打开成功工作流 `4b566547-961b-4e10-a8d0-99431f2e2229`。
3. 依次展示 `relax -> SCF -> BAND -> DOS`，核对 Job `40212 / 40250 / 40251 / 40252`。
4. 展开每一步 attempt，展示状态事件、受限日志、输入文件哈希、输出文件哈希和资源记录。
5. 强调后一阶段只在前一阶段科学验收通过后出现。

本节是固定真实工作流的只读演示复跑。演示期间不得提交新的 VASP 作业，除非用户另行明确授权一次新的计算；旧 Job 和原始 attempt 不得修改。

## 4. 科学结果

1. 打开 `/dashboard/results/4b566547-961b-4e10-a8d0-99431f2e2229`。
2. 展示最终结构和晶体信息；旋转 3D 结构，确认 Canvas 非空且交互正常。
3. 展示 BAND 图，核对带隙约 `1.6919 eV`，缩放或悬停确认图表可交互。
4. 展示 DOS 图，确认曲线、坐标轴和图例正常。
5. 依次下载 CIF、POSCAR、BAND 原始数据、DOS 原始数据和成功证据包。
6. 说明证据包 SHA-256 为 `a99e338c6a00fa2d1129bf9fbbe910a959f3c419955370f995da8242850ba8b4`。

验收点：结构、图和下载均来自同一固定工作流；缺文件或解析失败时页面不得显示成功。

## 6. 数据库与角色对照

1. 打开 `/dashboard/database/vasp`，展示固定真实记录和周期表筛选。
2. 从数据库记录进入成功/失败详情，确认 workflow ID 和结果页一致。
3. 回到 Viewer 新会话重复打开成功结果、日志和 VASP 数据库。
4. 在 Viewer 确认所有写控件仍禁用，下载仅限白名单工件。
